# 🎃 Projeto Halloween – Noite das Bruxas 👻

## 📌 Sobre o Projeto

O Projeto Halloween – Noite das Bruxas é uma página web temática desenvolvida para celebrar uma das datas mais populares e misteriosas do ano: o Halloween, comemorado em 31 de outubro.

O projeto apresenta uma experiência visual interativa e imersiva, reunindo elementos clássicos da cultura do Halloween, personagens icônicos do terror, sugestões de decoração, curiosidades e músicas temáticas.

A proposta é criar um ambiente digital que transmita a atmosfera misteriosa dessa celebração, combinando criatividade, entretenimento e desenvolvimento Front-End.

## ✨ Funcionalidades

- 🎃 Página Inicial: apresentação temática com destaque para o Halloween, chamada principal e elementos visuais relacionados à celebração.
- 👻 Seção Sobre: conteúdo informativo sobre a tradição do Halloween e sua história.
- 🧛 Galeria de Personagens: apresentação de personagens clássicos do terror, incluindo vampiros, bruxas, esqueletos, fantasmas e figuras famosas do cinema.
- 🕸️ Inspirações para Decoração: galeria visual com ideias para criar ambientes temáticos, utilizando abóboras, luzes, castelos, florestas e outros elementos.
- 🎵 Seção Musical: espaço dedicado a músicas e clipes relacionados ao Halloween, incluindo clássicos como Thriller e This Is Halloween.
- 🦇 Elementos Interativos: navegação entre seções, efeitos visuais e recursos que tornam a experiência mais dinâmica.
- 🍬 Chamada Final: encerramento temático convidando o visitante a entrar no clima da celebração.

## 🎨 Design e Identidade Visual

O projeto utiliza uma identidade visual inspirada no universo do Halloween, explorando elementos como:

- Abóboras iluminadas.
- Fantasmas e morcegos.
- Aranhas e teias.
- Castelos e florestas misteriosas.
- Personagens clássicos do terror.
- Efeitos visuais que reforçam a atmosfera temática.

A organização das seções busca proporcionar uma navegação agradável, apresentando diferentes conteúdos de maneira visualmente atrativa.

## 🎯 Objetivo do Projeto

O principal objetivo foi desenvolver uma página temática que reunisse diferentes elementos do Halloween em uma única experiência digital.

Além da proposta visual e recreativa, o desenvolvimento também representa uma oportunidade de praticar conceitos importantes do Front-End, como estruturação de páginas, estilização, organização de componentes visuais e implementação de interatividade.
